# First ESP32 Assignment 

## Goal: 
- Make a blinking LED using the ESP32 Controller
- I will be using a usb-C data cable to upload the code to the ESP32

## Steps: 
1. Install extensions (PlatformIO, Serial Monitor)
2. Modify the skeleton code to print out "Hello" to the terminal
3. Modify the skeleton code to flash the LED on the ESP32 on repeat
4. Modify the skeleton code to make the flashing LED send a message in morse code ("Hello")
5. Build the code
6. Connect the ESP32 to my laptop via USB-C 
7. Upload and monitor the code
8. Trouble shooting (e.g. fixing code errors, changing the baud rate, etc.) 
9. Record the flashing / terminal output
