## Lab 3:

# Lab Objectives: 
- Connect a sensor to an ESP32 Microcontroller
- Learn how sensors work
- Learn how potentiometers work
- Learn how a motion sensor works

# Methods Used:
- OS: Windows 10 LTSC IoT
- PlatformIO (Visual Studio Code extension) was used to upload code to the ESP32 over a usb-c cable. Code was written in C++ in Visual Studio Code.
- Serial Monitor (extension) was used to monitor serial outputs in the console
